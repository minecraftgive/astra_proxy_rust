# T9 rule matching validation (2026-11-03)

Keyword rules compile to an overlapping Aho-Corasick matcher. Every hit still competes by original Entry.index, including duplicate and nested keywords. Domain patterns compile into label arrays grouped by label count; requests split the domain once. Explanation queries reconstruct the original normalized pattern. Host IP parsing is shared by IP and domain matching. Already lowercase ASCII process names and POSIX paths can be borrowed without allocating; Unicode lowercase and Windows path normalization retain their original semantics.

GeoIP CIDRs become sorted disjoint intervals, merging duplicates, overlaps and adjacent ranges. Lookup checks the outer bounds then uses partition_point. IPv4-mapped addresses, empty groups and inverse matching retain their previous behavior.

## Criterion before/after

Command: `cargo bench -p astra-rule --bench matching -- --save-baseline before`, followed by `cargo bench -p astra-rule --bench matching -- --baseline before` after implementation. Windows x86_64 MSVC, optimized profile, Criterion 0.5.1, 20 samples, 1-second warmup and 2-second measurement per case.

| Case | Before estimate (interval) | After estimate (interval) |
| --- | --- | --- |
| 10,000 keywords, final keyword hit | 66.809 us (62.890–70.220) | 446.72 ns (367.70–535.28) |
| 10,000 three-label patterns, four-label domain miss | 1.5587 ms (1.4350–1.6953) | 691.12 ns (540.27–893.53) |
| 50,000 IPv4 CIDRs, final interval hit | 51.823 ns (50.839–52.926) | 11.146 ns (8.5062–13.431) |
| 50,000 IPv4 CIDRs, address above all intervals | 55.665 ns (52.056–59.639) | 12.244 ns (8.9109–16.213) |

The machine was concurrently building other worktrees, so timings have substantial scheduling noise. These fixtures specifically exercise bulk keyword search, label-count rejection and GeoIP edge checks, not every production distribution. Same-arity wildcard matches and middle-interval binary search remain linear-in-pattern-count and logarithmic-in-range-count respectively; no universal speedup is claimed. An initial interval implementation without outer-bound checks regressed this five-prefix-length GeoIP fixture, which prompted the bounds shortcut. Raw Criterion measurements remain under the shared target/criterion directory.
