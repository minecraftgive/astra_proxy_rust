## 已获得的验证证据

- 最新原生 GUI 库测试 65 项通过，包含原始单键误触、重复撤销、隐藏编辑器、弹窗归属、多窗口异步结果、服务端页限制。
- 真进程端到端测试：独立临时目录运行 manager 和 proxy；从原生测试窗口连接，切模式、切代理、建立并关闭 loopback SOCKS 连接、保存配置、检查退出存档，1 项通过。
- macOS 原生窗口人工检查：总览、搜索输入 `qp/ 1234567`、创建配置进入编辑器、设置中的真实程序信息、监控、更新不可用原因、任务页。操作仅使用隔离临时目录。
- F3 安装测试 17 项通过：GUI manifest 选择、TUI 兼容、Linux desktop、macOS app 与图标、已有入口冲突保护。
- 打包布局测试 2 项通过，覆盖 Linux、Windows、macOS Intel/Apple Silicon 的资源和 manifest。本机 Python 3.9 使用仅运行时的延迟注解兼容加载器，未改动产品脚本；CI 使用 Python 3.13。完整发布构建由独立 CI 作业执行，保留现有 fat LTO。
- 提权测试未发起真实 sudo/UAC；覆盖密码输入取消、清零、父进程终止、晚到票据撤销和退出等待。真实 askpass 窗口系统取消返回 1，stdout 为空。
- 退出冒烟曾发现 macOS 原生 terminate 提前结束进程的竞态，已改为持久化确认后停止事件循环。SIGTERM 和系统退出两条路径均验证了会话写入、后台回收及退出码 0；存档失败保留窗口，写入期间新编辑会重新存档。
